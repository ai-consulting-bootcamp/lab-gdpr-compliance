# Repo File Guide

This repository is organized into a few Markdown files, each with a specific role:

- `README.md` - top-level project overview and submission instructions.
- `instructions.md` - lab directions, required deliverables, and workflow steps.
- `rubric.md` - grading criteria used to evaluate the submission.
- `EU AI Act - Mudit-Cases.md` - AI Act scenario set with two tabs: the four case briefs and the answer key.
- `EU AI Act Approval Pack - Mudit-consulting-Parisa.md` - completed AI Act review for Parisa's cases, including case summaries, classifications, and compliance notes.
- `GDPR-Mudit-Cases.md` - GDPR scenario set in the same two-tab structure as the AI Act file, but with answer-key categories framed by GDPR articles and obligations.
- `GDPR-Parisa-Cases.md` - GDPR case file for Parisa's scenarios, structured like the AI Act file with case briefs and a private answer-key section.
- `GDPR-Parisa-Memo.md` - working GDPR audit file for the selected case, including the transition note, fact pattern, and audit worksheet.

If more case files or memo drafts are added later, they should follow the same pattern: one file for the scenario set, one file for the answer key or audit worksheet, and one file for the final memo or report.
