# GDPR Audit Pack — CV Screening with Human Review

This folder contains the completed **Same product, privacy lens** lab for **Option B(b)**.

## Scenario

An HR-tech startup sells a recruitment tool that ranks job applicants using structured and unstructured CV data. A recruiter reviews, confirms, or overrides the shortlist.

## Files

| File | Contents |
|---|---|
| `gdpr_audit_pack_cv_screening.md` | Fact pattern, transition note, Sections A–C of the mini GDPR audit, client recommendation memo, peer-review self-check, DPIA outline, and privacy-by-design checklist. |

## Working assumptions

The scenario assumes an EU-based HR-tech startup, EU/EEA applicants, an EU cloud environment, an ATS integration, and a non-EU AI/API vendor used for model inference or development. Replace these assumptions with real company, vendor, retention, and transfer details before professional use.

This is an educational consulting exercise, not legal advice.
